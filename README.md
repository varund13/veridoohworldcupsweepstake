# World Cup 2026 — Last Man Standing Sweepstake

A digital version of the "48 envelopes on the wall" office sweepstake. Every staff member is
secretly sealed inside a country envelope. As countries are knocked out of the FIFA World Cup 2026,
their envelopes open to reveal who's eliminated. The last person whose country is still alive wins.

## Files
- `sweepstake.html` — the whole app (admin tool **and** public board, one file).
- `board.json` — the public snapshot (generated by Export). Deploy this alongside the HTML.

## Two modes (automatic)
- **Open the file locally** (double-click → `file://`) → **Admin / authoring mode**. The sealed
  draw lives only in your browser. This is how the 2 admins run it.
- **Served from a URL with `board.json` present** (Netlify) → **read-only LIVE board**. No admin
  controls, and the sealed mapping is never present, so nothing can leak.

## Admin passphrase
Set in `sweepstake.html` → `const ADMIN_PASS`. Default `veridooh2026`. Change it.
(Only matters locally — the deployed board has no admin powers at all.)

## How to run it

### 1. Draw (once, before the tournament)
1. Open `sweepstake.html` locally. Click **🔑 Admin**, enter passphrase.
2. Confirm `PEOPLE` in the file totals exactly 48 (currently 48: 45 from the org chart + Aaron,
   Yamit, Puskar). Edit the list if needed.
3. Click **🎲 Draw & Seal** — shuffles everyone into the 48 country envelopes.
4. Click **⬇ Export board.json**.
5. Deploy `sweepstake.html` + `board.json` to Netlify. Public now sees 48 sealed envelopes.

### 2. Group stage — knocking teams out
1. Locally in Admin mode, open the **Envelopes** tab.
2. When a team is officially out, click **✉️ Knock out & reveal** on its envelope → the name is shown.
3. Click **⬇ Export board.json**, redeploy to Netlify. Public board updates.

### 3. Knockout stage — the bracket
1. Once group stage is done and 32 teams remain, go to **🕸️ Bracket** → **Build knockout bracket**.
2. Assign the 32 survivors into the Round of 32 (dropdowns).
3. As matches finish, click the **winning team** — they advance and the **loser's envelope opens
   automatically**. `↺` undoes a match.
4. Export + redeploy after each update.
5. When the Final is decided, the champion's holder is revealed as the **winner**.

## Important notes / limitations
- **Headcount must be exactly 48.** When the 2–3 interns are added you'll be over 48 — decide then
  whether to pair extras into shared envelopes or hold them as reserves (not yet built).
- **Updates are not real-time** — the public board changes only when you re-deploy `board.json`.
  This was the chosen trade-off (cheapest hosted option, no backend).
- **Security is "good for an office game," not Fort Knox.** The deployed board only ever contains
  already-public info (eliminated names, bracket, champion). The sealed mapping stays on the admins'
  machines (browser localStorage). Don't share your local browser profile / exported full state.
- Don't deploy `.claude/` — only `sweepstake.html` and `board.json` need to go to Netlify.
